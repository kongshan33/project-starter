# 产品行为

状态：模板示例已定义；新产品需求待初始化后填写。

## 模板用户流程

1. 打开首页，输入不超过 120 字符的标题。
2. 选择 Create preview，通过真实本地 API 获取预览。
3. 请求开始即防重复提交；超过 600ms 才显示按钮中的等待文字。
4. 成功后显示规范化标题和计数。预览不保存。
5. 再次请求期间保留旧预览。失败时保留输入和旧结果，允许再次提交。
6. 离开页面时取消客户端请求，卸载后的结果不改变当前视图。

组件展示页演示颜色、按钮、字段、错误、禁用与缺省内容；展示按钮不执行业务动作。

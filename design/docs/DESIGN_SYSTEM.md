# 设计规范

状态：模板默认规范。基础灰阶与异步反馈经验来自 Libitu，业务色和业务布局已移除。
规范入口只有本文件；实际 token 在 `packages/ui/src/tokens.css`，可运行展示在
`/design-system`。设计草案、参考与历史资料按 `design/README.md` 标记。

## 基础

- 白色页面、中性灰表面、黑色主操作；用留白、字号与层级组织信息。
- 默认字体为系统 sans 栈，可使用已安装的 Inter；没有远程字体请求。
  替换为本地字体时带上许可并重新检查换行。
- 基础间距为 4 / 8 / 12 / 16 / 24 / 32 / 48px；正文 16px，辅助文字 14px。
  页面标题可响应式变化；控件字体至少 16px。
- 卡片默认 12px 圆角，字段 8px，操作按钮为 pill。只有明确角色需要时使用其他形状。
- 单页面保持明确的主要操作。导航与操作分离；链接使用真实 href。

## 色彩语义

| Token | 默认值 | 用途 |
| --- | --- | --- |
| `--ink` | `#0c0c0c` | 主文字、主操作 |
| `--text-secondary` | `#525252` | 说明 |
| `--text-muted` | `#6b6b6b` | 弱化内容 |
| `--surface` / `--surface-soft` | `#fafafa` / `#ededed` | 内部表面 |
| `--line` / `--line-strong` | `#e5e5e5` / `#d4d4d4` | 非交互分隔 |
| `--control-border` | `#767676` | 控件可辨识边界 |
| `--brand` | `#5a43d6` | 可替换的品牌强调 |
| `--danger` | `#a3372b` | 错误与危险动作 |

基础灰 RGB 通道相等。颜色通过语义 token 引用，业务页面不再创建一套灰阶。
普通文本与实际背景目标对比度至少 4.5:1；重要控件边界与焦点至少 3:1。
选择、成功和错误同时提供文本/语义状态，不能只用颜色。

## 控件与状态

- Button 默认 `type=button`，提交显式使用 submit；按真实任务选择 primary /
  secondary / ghost / danger。导航不伪装为 button。
- 立即阻止重复提交并标记 `aria-busy`；600ms 是可调反馈默认值，不延迟请求。
  进度覆盖层保持按钮尺寸，辅助技术可访问的操作名称保持稳定。
- 初次无内容可用骨架；刷新保留现有结果和输入，失败提供明确下一步。
- Input/Textarea 配可见 label、必要时用 aria-describedby 关联提示与错误。
  验证错误在交互后出现；用户修改时清除旧错误，不在首次渲染吓阻输入。
- 使用原生按钮、输入、链接；模态场景优先使用原生 dialog，并验收焦点恢复。
  本模板未捆绑 dialog 组件；加入后需补充可运行示例。

## 响应式与可访问性

窄屏单列、自然换行；不挤压桌面多栏。默认控件最小高度 44px，粗指针 48px。
保留 visible focus，支持键盘与 200% 缩放。`prefers-reduced-motion` 禁用非必要动画；
`forced-colors` 使用系统边界和焦点颜色。页面语言与实际文字一致。
通用修改至少检查桌面、390px 窄屏、键盘和减少动画模式。

## 修改规范

变更 token → 变更组件/展示 → 更新本文件 → 运行对应验收。
产品特例放功能文档并说明范围，不把特例悄悄扩展成全局规则。
